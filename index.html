        Fonctionnement et limites

        Le dossier est lu dans votre navigateur : seuls les noms, tailles et dates de modification sont lus, jamais le contenu des fichiers. Rien n’est envoyé en ligne. Les bibliothèques sont incluses avec l’outil.

        Edge et Chrome : la profondeur max. évite de lire les niveaux non affichés, les dossiers vides apparaissent et vous choisissez où enregistrer l’Excel. Firefox et Safari : le navigateur liste tout le dossier avant l’analyse, les dossiers vides n’apparaissent pas (sauf par glisser-déposer) et l’Excel est téléchargé. Le navigateur peut afficher « Importer N fichiers sur ce site ? » : rien n’est importé, il demande seulement l’accès à la liste.

        Le navigateur ne donne jamais le chemin complet du dossier. Pour obtenir des liens cliquables vers les sous-dossiers dans l’Excel, collez ce chemin (ex. P:\Projets\12345) dans le champ prévu avant l’export.

        La date d’un dossier est celle du fichier le plus récent qu’il contient, sous-dossiers compris : le navigateur ne fournit pas la date de modification des dossiers.

        Comme le script Python, les fichiers temporaires et système (Thumbs.db, desktop.ini, .DS_Store, ~$…, .log, .tmp) sont ignorés et comptés dans les informations de lecture.

        Pour un très gros lecteur réseau, le script Python fourni dans le dépôt (dossier python/) produit le même Excel.
